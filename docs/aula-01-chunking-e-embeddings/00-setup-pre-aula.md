# Setup pré-aula — escolha sua versão

> **Faça o setup EM CASA, antes da aula.** A instalação baixa mais de 1 GB e o modelo de embedding tem ~470 MB — não dá para fazer isso no Wi-Fi da sala com a turma toda.

Escolha o guia do **seu terminal**:

| Seu ambiente | Guia |
|--------------|------|
| **Linux**, **macOS** ou **Git Bash** no Windows | [bash/00-setup-pre-aula.md](bash/00-setup-pre-aula.md) |
| **Windows com PowerShell** | [powershell/00-setup-pre-aula.md](powershell/00-setup-pre-aula.md) |

Na dúvida (Windows): se o seu prompt parece `PS C:\...>`, use a versão **PowerShell**; se parece `usuario@maquina MINGW64 ~`, use a versão **bash**.

**Importante:** escolha uma versão e siga **só ela** até o fim — não misture comandos das duas.
